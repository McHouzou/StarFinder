# StarFinder
Program to locate stellar object's live altazimuth coordinates. Intended for use in a project for telescope automation.

Object name/coordinates and geographic location choice are made by the user. In case the object and geographical location names are not found in the database, the program will have to be given the name of a nearby city/town (or explicit geographical coordinates), and the explicit equatorial coordinates.

The program then uses live time/date information to display the live position of the object in the sky, in altazimuthian coordinates.
